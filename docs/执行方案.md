## 执行顺序

### 1. 项目隔离与依赖

1. 在项目目录建立独立 Git 仓库，确认 `git rev-parse --show-toplevel` 返回项目目录。
2. 添加 `.gitignore`，忽略 Python 缓存、虚拟环境、生成的 `output_tokens.npz`、报告编译辅助文件和大型提供数据；保留源码、依赖清单、必要图像或其获取方法。
3. 核对 `python -m pip install -r requirements.txt`；保留当前三项依赖及版本范围。
4. 对起始文件作首次提交，形成可核对的原始基线。此后按功能分次提交，不能伪造历史。

### 2. 六组 NumPy 实现与阶段检查

只改 `image_encoder.py`。每一步先运行对应 `check.py` 阶段确认基线失败，再实现、复跑并提交。

1. **TODO-01 patchify**：`[B,3,224,224]` 拆成 7×7 个 32×32 图像块。先整理成 `[B,3,7,32,7,32]`，再转成 `[B,7,7,3,32,32]`，最后展平为 `[B,49,3072]`。运行 `python check.py --stage patches`。
2. **TODO-05 embed**：`patches @ patch_weight.T` 得 `[B,49,768]`；沿 token 轴在前面连接 CLS，加入位置向量。运行 `python check.py --stage tokens`。
3. **TODO-02 split_heads**：`[B,N,768]` 整理成 `[B,N,12,64]`，交换 N 和 H 两轴，得到 `[B,12,N,64]`。用非对称测试值确认 token/head 次序。
4. **TODO-03 attention**：计算 `q @ k.transpose(0,1,3,2) / sqrt(64)`；使用提供的 `attention_weights`，计算 `coefficients @ v`，转置、合并回 `[B,N,768]`，以 `out_weight.T` 加偏置投影。检查 causal 路径仍能使用提供的 mask。
5. **TODO-04 TransformerBlock**：第一次残差为 `x + attention(norm1(x))`；`u=norm2(residual)`；MLP 为 `GELU(u @ fc1_weight.T + fc1_bias) @ fc2_weight.T + fc2_bias`；返回第二次残差。运行 `python check.py --stage block0`。
6. **TODO-06 output**：对第 0 个 CLS token 做 post-Norm，再乘 `[768,512]` 的 `visual.proj`，交给已提供的 `unit_vector`。运行 `python check.py --stage last_tokens`、`output`、`batch`、`all`。

阶段检查必须同时满足形状、`float32`、有限值和参考容差。`output` 容差为 `atol=2e-5, rtol=2e-4`，内部 token 为 `atol=2e-4, rtol=2e-4`。运行 `python run.py --output output_tokens.npz`，核对十个 ID、`[10,512]` 形状和每行单位长度。保存每个阶段打印的最大/平均绝对误差作为报告证据。
